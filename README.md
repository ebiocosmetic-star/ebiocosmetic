## 📖 1. Descripción del Proyecto

Somos un emprendimiento dedicado a la elaboración de **jabones artesanales**, inspirados en la riqueza natural de la **Amazonía** y en los ingredientes ancestrales de nuestra **Comunidad Nativa de Infierno**. Elaboramos cada producto con dedicación, creatividad y amor por lo natural.

Mediante la elaboración de jabones artesanales a base de **copaiba**, **capirona** y **sangre de grado**, promovemos:
* **Participación comunitaria:** Fomentamos el trabajo conjunto, el intercambio de conocimientos y la valoración de las habilidades artesanales locales.
* **Conservación de la biodiversidad:** Realizamos una recolección consciente y responsable de recursos naturales sin deforestación ni daño a los árboles vivos.
* **Reducción de residuos:** Empleamos empaques biodegradables y procesos de residuo cero (Zero Waste).
* **Desarrollo sostenible:** Generamos oportunidades de desarrollo económico y social para nuestra comunidad, respetando nuestras tradiciones culturales y fortaleciendo el compromiso activo con la protección de la Amazonía.

## 🌿 2. Nuestros Bioactivos Sagrados

| Ingrediente | Nombre Científico | Propiedades Principales | Ideal Para |
| :--- | :--- | :--- | :--- |
| **Copaiba** | *Copaifera officinalis* | Antiinflamatorio, calmante, antiséptico y cicatrizante profundo. | Pieles sensibles, con acné o reactivas. |
| **Capirona** | *Calycophyllum spruceanum* | Despigmentante suave, regenerador celular, reafirmante y rico en taninos. | Pieles maduras o con manchas solares. |
| **Sangre de Grado** | *Croton lechleri* | Savia roja cicatrizante, estimula la formación de colágeno y efecto tensor. | Todo tipo de piel, líneas de expresión y microlesiones. |

## 🧼 3. Catálogo de Productos

1. **Jabón Artesanal de Copaiba (100g):** Limpieza purificante profunda y alivio inmediato para pieles delicadas o propensas a imperfecciones.
2. **Jabón Artesanal de Capirona (100g):** Efecto renovador y tonificante que unifica la textura y luminosidad del rostro y cuerpo.
3. **Jabón Artesanal de Sangre de Grado (100g):** El escudo antioxidante y reparador milenario para el cuidado diario.
4. **Kit Trilogía Amazónica:** Pack de colección con las 3 barras + jabonera de madera recuperada + envoltura en fibras naturales de la comunidad.

## 🚀 5. Cómo Ver la Web Localmente

1. Clona el repositorio:
   ```bash
   git clone https://github.com/ebiocosmetic-star/ebiocosmetic.git
   cd ebiocosmetic
   ```
2. Abre el archivo `index.html` en cualquier navegador web moderno (doble clic o usando una extensión como Live Server en VS Code).

## 🌐 6. Despliegue en GitHub Pages (Página Web Pública)

Para activar el sitio web públicamente y gratis con GitHub Pages:

1. Ingresa a tu repositorio en GitHub: [https://github.com/ebiocosmetic-star/ebiocosmetic](https://github.com/ebiocosmetic-star/ebiocosmetic)
2. Ve a la pestaña **Settings** (Configuración) > **Pages** (en el menú lateral izquierdo).
3. En **Branch**, selecciona la rama `main` y la carpeta `/ (root)`.
4. Haz clic en **Save** (Guardar).
5. En pocos minutos, tu sitio web estará disponible en:
   👉 **`https://ebiocosmetic-star.github.io/ebiocosmetic/`**
